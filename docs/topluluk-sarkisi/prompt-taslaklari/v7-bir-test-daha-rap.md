# 7. Şarkı: Bir Test Daha (Türkçe rap, takım yoklaması)

- **Eser adı:** Bir Test Daha
- **Süre hedefi:** 2:45–3:15
- **Radyodaki yeri:** "Bunu biliyor muydunuz?" arasından sonra

## Style of Music

```
Turkish hip hop, 92 BPM boom bap beat, punchy kick and snare, gritty bass, scratched vinyl hooks, workshop sounds as percussion (hammer taps, drill whirr), confident male rap verses, energetic female hook, crowd shouts on chorus, motivational, clean mix
```

## Exclude Styles

```
spoken directives, meta text, narration of instructions, trap hi-hat rolls, drill, autotune heavy, sad, lo-fi, violent lyrics
```
