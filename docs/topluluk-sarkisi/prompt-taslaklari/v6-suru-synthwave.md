# 6. Şarkı: Sürü (sözsüz, elektronik)

> Hava araçları takımları için sözsüz, enerjik bir parça. **Instrumental** açık üretilmeli.

- **Eser adı:** Sürü
- **Süre hedefi:** 2:30–3:00
- **Radyodaki yeri:** "Gökyüzündeki takımlarımız" arası ile "Atölyeden Göklere" arasında ya da sonrasında

## Style of Music

```
Synthwave electronic instrumental, 118 BPM, driving arpeggiated synths, pulsing bassline, punchy retro drums, soaring lead synth melody, drone propeller whirr textures panned left and right, radio telemetry beeps, sense of flight and takeoff, cinematic build and drop, no vocals
```

## Exclude Styles

```
vocals, singing, rap, spoken words, choir, lyrics, lo-fi, acoustic guitar, sad, dubstep wobble
```

## Notlar

- Pervane sesleri çok baskın olursa "subtle propeller textures" olarak yumuşatın.
