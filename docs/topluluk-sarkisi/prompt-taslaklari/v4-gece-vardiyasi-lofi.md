# 4. Şarkı: Gece Vardiyası (sözsüz, lo-fi)

> Radyo için arka planda dinlenecek, sözsüz bir parça. Suno/Udio'da **Instrumental**
> seçeneği açık üretilmeli.

- **Eser adı:** Gece Vardiyası
- **Süre hedefi:** 2:30–3:00
- **Radyodaki yeri:** "Atölyede bir gece" arasından sonra

## Style of Music

```
Lo-fi hip hop instrumental, 82 BPM, warm dusty drums, soft vinyl crackle, mellow Rhodes chords, subtle workshop ambience, quiet soldering iron hiss, distant mechanical keyboard typing, gentle 3D printer hum as texture, late night focus, calm, cozy, no vocals
```

## Exclude Styles

```
vocals, singing, rap, spoken words, choir, lyrics, aggressive drums, distortion, EDM drop, sad piano ballad
```

## Notlar

- Sözsüz olduğu için olgu kontrolü gerekmez.
- Atölye sesleri ritmin önüne geçmemeli; kısık doku olarak kalmalı.

## Üretim sonucu

- Dosya: `ses/07-the-bursa-shift.mp4`, başlık **The Bursa Shift** (2:57), sözsüz.
- Radyoda "Atölyede gece" bağlantısından sonra çalar; aynı zamanda eski radyo
  sürümünde konuşmaların müzik yatağıydı.
