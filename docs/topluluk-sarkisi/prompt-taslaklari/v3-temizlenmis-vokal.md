# 3. Versiyon: Temizlenmiş ve Optimize Vokal (prompt taslağı)

> Gemini ile hazırlanan prompt belgesi. Sözlerde hiç köşeli parantezli bölüm etiketi veya
> sahne talimatı yok; amaç, ses motorunun "workshop sounds", "snare build" gibi talimatları
> yanlışlıkla seslendirmesini önlemek. Tüm müzik yönlendirmesi stil alanındadır.

- **Eser adı:** Atölyede Başlar (Vokal Optimizasyonlu Sürüm)

## Style of Music

```
Anthemic Turkish rock and electronic hybrid, 126 BPM, driving rhythm, palm-muted guitars, prominent workshop mechanical ambience embedded in rhythm, powerful bass, energetic punchy drums, uplifting student stadium choir, charismatic clear male lead, modern clean production, inspiring engineering showcase.
```

## Exclude Styles

```
spoken directives, meta text, narration of instructions, sad, slow, lo-fi, trap, screaming
```
